# Funnel Analysis Assignment

## Objective
Analyze a user signup funnel using Python and Pandas.

## Dataset
Event-level funnel data containing: 
- user_id
- step
- timestamp

## Analysis Performed
- Counted unique users at each funnel stage
- Calculated stage-to-stage conversion rates
- Identified the biggest drop-off
- Visualized the funnel using a bar chart

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Output
The notebook calculates:
- Unique users at each stage
- Conversion percentages
- Largest drop-off stage
- Funnel visualization
- Recommendation for improvement
